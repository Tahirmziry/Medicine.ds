MEDICINE D.S. — نسخة جاهزة للرفع إلى GitHub Pages

محتويات المجلد:
- index.html: الصفحة الرئيسية والحاسبة وجدول الأسعار.
- medicine-ds-logo.png و medicine-ds-icon.png: ملفات الهوية.
- about.html و privacy.html و contact.html: صفحات معلومات الموقع.
- .nojekyll: لتسهيل نشر الملفات الثابتة.

طريقة الرفع:
1) فك ضغط ZIP.
2) افتح مستودع GitHub Medicine.ds.
3) ارفع جميع الملفات والمجلدات الموجودة هنا إلى جذر المستودع (وليس ملف ZIP فقط).
4) من Settings ثم Pages اختر Deploy from a branch، ثم Branch: main و Folder: / (root)، ثم Save.
5) انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages.

ملاحظات مهمة:
- GitHub Pages استضافة ثابتة؛ لا تشغّل Netlify Functions أو قواعد بيانات خلفية. لذلك عدّاد الزوار يبقى ظاهراً لكنه لا يحسب بعد، إلى أن نربطه بخدمة عدّاد خارجية مناسبة.
- لا توجد إعلانات فعلية في هذه النسخة. بعد نشر الموقع ومراجعته وربطه بحساب AdSense الموافق عليه، نضيف كود الإعلانات الحقيقي.
- قبل طلب مراجعة AdSense، أضف وسيلة تواصل حقيقية إلى contact.html وراجع سياسة الخصوصية لتطابق الخدمات التي ستفعّلها فعلاً.
- لم يتم نشر الموقع على GitHub من هنا؛ هذه حزمة جاهزة للرفع.
